# Daan Roosenbrand

Site van Daan Roosenbrand — saxofoon, klarinet, directie en docent. Rotterdam.

## Netlify

| Instelling | Waarde |
| --- | --- |
| Build command | `npm run build` |
| Publish directory | `dist` |
| Node | 22 |

`netlify.toml` zet dit al. Koppel de repo, deploy, klaar. Nitro bouwt de site als Netlify-functie; onbekende paden krijgen de 404-pagina.
